
# 🎯 AI English Verb Practice Agent (AI 英语动词智能训练营)

这是一个专为英语学习者设计的**智能动词情景练习与进度追踪工具**。项目基于 **Python + Streamlit** 编写，并利用 **Google Gemini API** 实现高度智能化、场景化的口语表达与同义词运用评估。

## 🌟 核心特色

### 1. 3层随机锚点设计（告别重复问题）

为了解决传统大语言模型（LLM）出题容易千篇一律、重复提问的痛点，本项目设计了以下随机组合机制：

* **目标动词调度**：基于间隔重复算法，优先调度未背诵、低熟练度或星标收藏的动词。
* **50+ 日常生活场景库**：系统随机将考题嵌入如*“餐厅点餐”、“看牙医”、“邻里纠纷”、“二手交易”、“电梯被困”*等极其生动的生活实景中。
* **高动态温度参数（Temp 0.9+）**：确保即便两次抽取到同一个单词，大模型生成的口语长句和情境对话也绝不重复，提供真正的沉浸式场景学习。

### 2. 语义级同义词与语法纠错评估

* 告别死板的字符串比对！如果您输入的动词在语境中完全地道（例如目标是 `close`，而您写了 `shut`），Gemini 会**智能判定正确**，并为您解析同义词间的细微口语差异。
* 如果您词义选对但时态错误（例如把 `written` 错写成 `write`），AI 助教会精准指出“词义正确但时态有误”，帮您建立扎实的语法基础。

### 3. 🎯 终极“无鼠流”全键盘流畅学习

专为键盘党优化，实现**手不离键盘**的高效沉浸式体验：

* **自动光标聚焦**：新题一加载，您的输入光标就会自动聚焦在输入框内，无需鼠标点击，直接开始输入。
* **双击 Enter 极速循环**：
  1. 输入答案 ➡️ 按下第一次 **`Enter`**（提交并看解析）。
  2. 看完解析 ➡️ 再次按下 **`Enter`**，系统秒开下一题，光标已自动定位，继续输入！

### 4. 本地学习数据库与进度追踪

* **SQLite 数据存储**：在本地静默维护答题进度。
* **间隔重复算法（SM-2 变体）**：根据答题表现，智能延长或缩短单词的下一次复习间隔（熟练度高则两周后复习，熟练度低则立即重温）。
* **错题本（Troubled Verbs）**：自动分析出“练习多次但正确率低于50%”的易错词汇，帮助您专项攻坚。
* **自建生词本**：支持手动录入您最近在看剧或阅读中遇到的新词汇。

### 5. 离线也能用

没有配置 API Key 时应用不会崩溃，而是自动切换到**离线模拟模式**：题目取自本地模板，批改基于词形比对（能区分”选错词”和”词对但时态错”）。配置好 Key 后即可无缝切回完整的 AI 出题与语义批改。

### 6. 词汇包管理与 Excel 自动同步

* **内置词包系统**：预置 6 大分类词包（核心常用、雅思、托福、学术写作、商务英语、日常生活），可在「词汇包管理」标签页按需启用/禁用。
* **Excel 自动同步**：将你的个人词汇表保存为 `packs/user_imported/Vocabulary.xlsx`（第一列为单词），**每次启动应用时自动导入数据库**，无需手动上传。编辑 Excel 后重启应用即可生效。
* **多格式导入**：支持通过界面导入 CSV / JSON / Excel 格式的自定义词包，也可使用 AI 按主题智能生成词包。

### 7. 环境变量与安全防泄露设计

* 采用标准的 `.env` 配置加载，本地敏感的 `GEMINI_API_KEY` 已经默认写进 [`.gitignore`](.gitignore)，确保将项目托管至 GitHub 时**绝无 API Key 泄露风险**。

## 🛠️ 项目结构

```text
├── .env.example             # API Key 环境变量公开模板
├── .gitignore               # Git 防火墙（忽略 .env, venv, SQLite 数据库）
├── .streamlit/config.toml   # 应用主题配置（明/暗双主题，无需自定义 CSS）
├── requirements.txt         # Python 依赖清单
├── Launch-AI-English-Verb-Practice.bat  # Windows 双击秒开启动器
├── verbs_data.py            # 50 个生活场景库（内置动词已迁移至词包系统）
├── db_manager.py            # 本地 SQLite 数据库读写及间隔重复排程逻辑
├── llm_client.py            # Gemini 客户端（支持结构化输出与离线模拟 fallback）
├── vocab_pack_manager.py    # 词包文件 I/O、CSV/Excel 解析、AI 词包生成
├── app.py                   # Streamlit 交互网页前端
└── packs/                   # 词包存储目录
    ├── builtin_*.json       # 内置词包（核心/雅思/托福/学术/商务/日常）
    └── user_imported/       # 用户文件导入目录
        └── Vocabulary.xlsx  # 个人词汇表（自动同步，第一列为单词）
```

## 🚀 快速启动

### 前提条件

1. 电脑中已安装 Python 3.10+ 环境（并在安装时勾选了 **Add Python to PATH**）。
2. 获取了 [Google AI Studio](https://aistudio.google.com/) 的免费 **Gemini API Key**。

### 运行步骤

1. **获取项目**：克隆本仓库到您的本地电脑。
2. **复制配置文件**：在根目录下将 `.env.example` 复制一份并重命名为 `.env`。
3. **填入密钥**：打开 `.env` 文件，填入您的真实 API 密钥：

   ```env
   GEMINI_API_KEY=AIzaSyD-xxxxxxxxxxxxxxxxxxxxx
   ```

   > 不想改文件？也可以直接在应用左侧边栏的「API 凭证管理」里粘贴 Key。留空则以离线模拟模式运行。
   >
4. **双击启动**：
   在 Windows 系统下直接**双击运行 `Launch-AI-English-Verb-Practice.bat`**。

   * *初次运行*：脚本会自动为您创建隔离的 Python 虚拟环境（venv）并自动安装所有依赖，完成后将强制弹开浏览器展示应用。
   * *后续运行*：1 秒内极速秒开！
